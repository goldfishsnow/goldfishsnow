## Goldfish 插件体系

插件按功能分为七大类，每个插件有固定编号（如 `01.01`、`06.02`）：

| 编号 | 分类 | 做什么 |
|---|---|---|
| 01 | 采集与输入 | 把网页、分享内容和 AI 对话收进库里 |
| 02 | 下载与媒体 | 视频、音频的下载、转换、整理与浏览 |
| 03 | 设备与路由 | 多设备环境下查看和巡检本机插件 |
| 04 | 安全与保护 | 系统文件锁、备份、网络状态等防护 |
| 05 | Linux 工具 | 在 Linux 上使用 Obsidian 的配套工具 |
| 06 | 系统与治理 | 插件登记、交接台账、依赖审计、版本留存 |
| 07 | 外观 | 文件树和界面的小改进 |

插件源码与版本发布在私有仓库中维护，暂不公开。
